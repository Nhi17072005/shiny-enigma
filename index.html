3. Bốn Tính Năng Bổ Sung (Extra Features)

Tính năng 1: Dark Mode Toggle

Cho phép người dùng chuyển đổi giữa chế độ sáng và tối.

/* Mã CSS hoặc JS liên quan */
body.dark-mode {
    background-color: #121212;
    color: #ffffff;
}

Tính năng 2: Smooth Scrolling & Sticky Nav

Thanh điều hướng cố định đỉnh trang và cuộn trang mượt mà khi bấm menu.

html {
    scroll-behavior: smooth;
}

Tính năng 3: Custom CSS Animations

Hiệu ứng xuất hiện mượt mà cho các thành phần nội dung khi di chuột.

.card:hover {
    transform: translateY(-5px);
    transition: all 0.3s ease;
}

Tính năng 4: Interactive Contact Form / Filter

Biểu mẫu hoặc bộ lọc dữ liệu tương tác linh hoạt cho người dùng.

/* CSS Styling cho Form/Filter */
.form-input:focus {
    border-color: #007bff;
    outline: none;
}
